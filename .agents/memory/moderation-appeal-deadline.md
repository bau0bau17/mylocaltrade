---
name: Moderation appeal deadline
description: The appeal eligibility window is distinct from the general complaints-response target.
---

Eligible moderation appeals use a 30-day window calculated from the decision timestamp. This is distinct from the 30-day substantive-response target for general complaints and must be described separately in user-facing copy.

**Why:** Reusing the complaints wording for appeal eligibility leaves users without a disclosed deadline and can create inconsistent enforcement between report types.

**How to apply:** Keep API eligibility and the Report Status deadline aligned. State the deadline only for eligible moderation appeals; do not imply that ordinary complaints have a 30-day submission deadline.
