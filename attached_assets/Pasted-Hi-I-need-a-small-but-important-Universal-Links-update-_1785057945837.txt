--------------------------------------------------

https://mylocaltrade.co.uk/.well-known/apple-app-site-association

https://mylocaltrade.co.uk/apple-app-site-association

- return HTTP 200
- not redirect
- have Content-Type: application/json
- have NO .json file extension in the public URL

            "/": "/open"

  }

www.mylocaltrade.co.uk

2. ADD /open ROUTE
--------------------------------------------------

Please add a valid public route:

/open

It must support these query parameters:

c=<conversationId>
t=leads
t=support

Examples:

https://mylocaltrade.co.uk/open?t=leads

https://mylocaltrade.co.uk/open?c=123

https://mylocaltrade.co.uk/open?t=support

This route must return HTTP 200 and must NOT show the current Angular 404 page.
